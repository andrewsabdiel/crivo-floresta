# Floresta · CRIVO

Experiência web de rolagem feita pela CRIVO. HTML, CSS e JavaScript simples, com GSAP e ScrollTrigger.

## Configuração

Edite `config.js`:

- `landingUrl`: URL final da landing (https://...). Vazio deixa o botão sem destino.
- `heroVideo`: caminhos do vídeo de abertura (`desktop` e `mobile`). Vazio usa só a imagem.

## Publicação

GitHub Pages, branch `main`, pasta raiz. Os caminhos são relativos.

## Créditos

- Imagens da floresta geradas por IA.
- Vídeo de abertura: Pexels (registrar autor, URL e licença ao adicionar).
- GSAP e ScrollTrigger: GreenSock.
